# bike-sales-dashboard
Excel dashboard analyzing bike sales data
## Overview
This project is an interactive Excel dashboard that analyzes bike sales data to uncover customer purchasing patterns and key business insight.
The dashboard provides a clear and visual representation of how different factors such as income, age, marital status, and region influence bike purchases.

## Objectives
- Analyze customer behavior in bike purchases
- Identify key factors affecting sales
- Present insights using a clean and interactive dashboard
- 
## Tools Used
- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Data Visualization ( Charts & Dashboard)
  
## Project Structure
- **Raw Data Sheet** -Original dataset
- **Data Cleaning(Working sheet)** -Prepared and cleaned data
- **Pivot Tables** - Data aggregation and analysis
- **Dashboard** - Visual representation of insights

## Key Insights
- Customers with higher income are more likely to purchase bikes
- Married individuals tend to buy more bikes than single customers
- Certain regions show higher sales performance
- Age group plays a role in purchasing decisions
